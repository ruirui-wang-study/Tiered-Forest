# Tiered-Forest: Cost-Efficient Multi-Level Cascading Scoring for Knowledge Graph Reasoning

**Tiered-Forest** 是一个专为知识图谱推理（KG Reasoning）设计的多级级联架构，其核心目标是在保证高准确率的同时，大幅降低对昂贵的大语言模型（LLM）的依赖，从而实现**成本与性能的最佳平衡**。

## 一、 Tiered-Forest 的设计思想

Tiered-Forest 的核心理念是 **"分层过滤，按需增强"**。它将推理过程设计为一个三层（Tier）的“漏斗”系统，通过从低成本到高成本的模型级联，逐步筛选和验证候选推理路径。

### 1. Tier 1: 符号过滤层 (Symbolic Filter)
*   **思想**：利用知识图谱的结构信息（如实体类型约束、跳数限制）进行极速、零成本的规则过滤。
*   **作用**：初筛，去除明显的错误路径，保证高召回率。

### 2. Tier 2: 语义评分层 (Semantic Scoring)
*   **思想**：利用轻量级的统计或语义模型（如 **Jaccard**, **SBERT**, **Cross-Encoder**）计算问题与路径的相似度。
*   **核心机制**：引入 **“Ambiguity Zone (模糊区间)”** 概念。
    *   **Fast-Pass (高置信度)**：分数极高的路径直接作为答案输出（无需 LLM）。
    *   **Discard (低置信度)**：分数极低的路径直接丢弃。
    *   **Ambiguity (模糊)**：只有分数处于中间模糊地带的路径，才会被送往下一层。

### 3. Tier 3: LLM 验证层 (LLM Validation)
*   **思想**：利用大模型（如 DeepSeek, GPT-4）强大的推理能力作为“最终裁判”。
*   **作用**：仅处理 Tier 2 无法确定的“模糊”路径，进行复杂的语义判别和消歧。

## 二、 与现有 KGQA 相关研究的优缺点对比

Tiered-Forest 主要与两类现有主流方法进行对比：**基于纯检索/嵌入的方法 (Traditional Retrieval)** 和 **基于纯 LLM 的生成/推理方法 (Pure LLM-based)**。

| 维度 | Tiered-Forest | 纯 LLM 方法 (如 DeepSeek-only) | 传统检索/嵌入方法 (如 EmbedKGQA, GraftNet) |
| :--- | :--- | :--- | :--- |
| **Token 成本** | **极低 (优点)** <br> 仅对极少数模糊路径调用 LLM，相比纯 LLM 方案可节省 **60%-80%** 的 Token。 | **极高 (缺点)** <br> 需要将所有候选子图或路径输入 LLM，上下文开销巨大。 | **低 (优点)** <br> 通常不需要 LLM，成本极低。 |
| **准确率** | **高 (优点)** <br> 结合了 LLM 的强推理能力，能在复杂语义上达到 SOTA 水平。 | **高 (优点)** <br> LLM 理解能力强，准确率通常是当前上限。 | **中等 (缺点)** <br> 难以处理复杂语义匹配（如 "Star Wars" vs "Star Trek" 的细微差别），容易受噪音干扰。 |
| **系统鲁棒性** | **强 (优点)** <br> 即使 Tier 2 模型较弱（如 Jaccard），只要“模糊区间”设置得当，LLM 仍能兜底挽救准确率。 | **强 (优点)** <br> 端到端生成，容错性较好。 | **弱 (缺点)** <br> 一旦检索模型评分错误，错误会直接传递到结果，无挽救机制。 |
| **复杂/时延** | **中等 (缺点)** <br> 多级流水线增加了系统复杂度和调优难度（需调整阈值），部分 Tier 2 模型（如 Cross-Encoder）会增加推理时间。 | **高 (缺点)** <br> LLM 生成速度慢，且受限于 API 速率限制。 | **低 (优点)** <br> 向量检索速度极快，适合即时响应。 |

## 三、 总结

**Tiered-Forest 的核心优势**在于它打破了“高精度=高成本”的魔咒。

*   相比 **纯 LLM**，它是一个**“省钱专家”**，用便宜的方法（Jaccard/Cross-Encoder）解决了 80% 的简单问题，只把钱花在 20% 的难题上。
*   相比 **传统检索**，它是一个**“智能增强版”**，在统计模型失效时，有 LLM 作为强大的后备军来保证最终质量。

在实验数据中，使用 **Cross-Encoder** 作为 Tier 2 时，相比纯 DeepSeek 方案节省了 **82%** 的 Token 且保持了 100% 的准确率，完美体现了这一架构的优越性。
