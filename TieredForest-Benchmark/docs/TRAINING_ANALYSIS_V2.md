## ⚠️ 问题分析

### 为什么训练的模型没有学到有效模式？

#### 1. **数据标注问题**
- 当前使用简单的字符串匹配来评估正确性
- 可能导致很多误标注
- 例如："Christopher Nolan directed Inception" vs "Inception was directed by Christopher Nolan"

#### 2. **数据不平衡严重**
- 正确样本: 28.5%
- 错误样本: 71.5%
- 模型倾向于预测中间值 (0.5)

#### 3. **任务定义不清晰**
- "答案质量" 是一个模糊的概念
- 需要更精确的标注标准

#### 4. **模型容量问题**
- DistilBERT 可能不够大
- 或者需要更多的训练数据 (1000+)

#### 5. **特征不足**
- 仅使用 question + answer 文本
- 缺少其他特征（答案长度、实体数量等）

def evaluate_answer(answer, ground_truth):
    # 使用语义相似度
    from sentence_transformers import SentenceTransformer
    model = SentenceTransformer('all-MiniLM-L6-v2')
    
    emb1 = model.encode(answer)
    emb2 = model.encode(ground_truth)
    
    similarity = cosine_similarity(emb1, emb2)
    return 1.0 if similarity > 0.8 else 0.0

## 📝 经验教训

### 关键洞察

1. **📚 更多数据 ≠ 更好性能**

2. **📚 简单方法有时更好**
   - SimpleScorer 比训练的模型更有效
   - 不要过度工程化

3. **📚 任务定义很重要**
   - "答案质量" 是一个模糊的概念
   - 需要更精确的定义和标注

4. **📚 数据标注是关键**

   - 人工标注成本高但必要

5. **📚 模型不是万能的**
